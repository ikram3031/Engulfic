### [E02] 2026-08-15: Enforced Required Phone Validation & Payload Formatting for Registration
- **Issue:** During registration, the phone number was handled as optional, and there was no proper client-side format validation for phone numbers.
- **Fix:**
  - The phone number field in `ProfileModal.jsx` was made required.
  - Regardless of whether the user enters `017XXXXXXXX` or `+88017XXXXXXXX`, the value is automatically converted/normalized to the `+8801[3-9]XXXXXXXXX` format before submission.
  - A proper Bangladesh phone number Regex validation check was added.

### [E01] 2026-08-15: Fixed Cart, Checkout and Navigation Routing Issues
- **Issue:** The `<Link>` component was incorrectly using the `href` attribute, and in `Navbar.jsx`, `useLocation()` was assigned directly to the `pathname` variable without destructuring it.
- **Fix:**
  - Replaced `<Link href="...">` with `<Link to="...">` in `Cart.jsx` and `CategoryGrid.jsx`.
  - Updated `Navbar.jsx` to use `const { pathname } = useLocation();`.
